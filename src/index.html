X 账号授权与 Cookie 导入

先通过 X OAuth 授权账号，再批量导入该账号的浏览器 cookie。cookie 只用于浏览器登录，不代替 OAuth；账号浏览器仍需安装 CommentCrate（exporter24 可选）。

1. 授权账号

在 X 登录并确认授权。每个账号需要分别授权。

2. 已授权账号

  • 正在读取…
显示 cookie 与浏览器就绪状态

3. 批量导入 Cookie

单账号：直接粘贴 Chrome 扩展导出的完整 cookie 数组，会自动从 twid 读取账号 ID。多账号：用 [{ "accountId": "...", "cookie": [...] }] 包装。

写入 .data/cookies/<账号ID>.json，权限 0600 


  
4. 自动选择存活账号执行

  
依次检查有 cookie 的已授权账号，使用第一个仍能登录的账号执行一轮 loop。

  

    
    
    
    筛选结果写入关注 Outbox；请运行主 loop 处理队列。
    
  

  

  自动任务在后台运行，日志：.data/auto-run.log；浏览器窗口会依次弹出。完整 loop 会实际发送关注请求。
